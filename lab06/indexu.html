Week 3: I'm back~

This page looks a little different than the last time you were here right? I added some things! In this module we delved into CSS, and I learned how to add styles onto the elements used within this webpage. There are 3 main ways to apply CSS to HTML code; the method I'm using here is called an external stylesheet. This allows me to maintain all my styles in one place, and keep the HTML code itself more organized. I also learned the structure of CSS rules, and how to use selectors to apply styles to specific portions of code. It's a lot of fun! I can't wait to learn more styling options.


Week 6: It never ends

It's actually pretty cool that I get to keep revisiting and rehauling this webpage. All of the styling choices from Week 3 have been completely changed, and I really like the new look. This week, (although I have been gravely ill...) we learned about responsive design, and methods of making webpages accessible on different devices. If you look at this page on your computer it will not look the same as it does on your phone! Reveal: That version has a navigation bar.

This was made possible by using a media query. Media queries are basically rules that only apply under certain conditions. Here, the condition is the width of the screen you're viewing this page on. If the width hits a specific number, the viewable style will change between my PC and mobile modes.
